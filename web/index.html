Actual Losses is indemnity plus medical as of the last valuation. Actual Primary Losses is calculated as you type, once payroll is entered; it is never typed. Open/Closed is shown on the worksheet only and does not change the calculation. Rare cases (subrogation, fraud, joint coverage, non-compensable, EL + WC, multi-person accidents) are under each claim's Special handling.

The Primary Threshold that results selects the D-ratio column in Table I, and it caps each claim's Actual Primary Losses at threshold − $250.
